# Security Policy

## Supported Laravel Versions

| Version | Security support |
|---------|------------------|
| 13.x    | :white_check_mark: |
| 12.x    | :white_check_mark: |
| 11.x and earlier | :x: |

Laravel 11 and earlier are outside this major release's Composer constraints.

## Supported Chart.js Versions

| Version | Security support |
|---------|------------------|
| 4.x     | :white_check_mark: |
| 3.x and earlier | :x: |

Chart.js 2 and 3 assets remain available for migrations. New applications should use Chart.js 4.

## Reporting a Vulnerability

If you discover a security vulnerability within this package, please email the Icehouse Ventures technology team at tech@icehouseventures.co.nz. All security vulnerabilities will be promptly addressed.
